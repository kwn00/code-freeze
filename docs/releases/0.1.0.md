# v0.1.0

## 달라진 점

- **첫 버전.** Friday Deploy 패밀리의 개발자 픽셀아트 타워디펜스입니다. 내일부터 연말 코드 프리즈인데, `main` 브랜치(길)를 따라 버그가 🖥️ prod 서버로 몰려옵니다. 길 옆 빈칸에 개발 도구(타워)를 지어 10번의 스프린트를 막으면 이깁니다.
  - prod 가용성 20. 버그가 prod 에 닿으면 버그마다 정해진 만큼(1~20) 줄고, 0 이 되면 `502 Bad Gateway` 로 집니다.
  - 돈은 SP(스토리 포인트). 처음 150, 버그를 잡으면 받고, 스프린트를 막으면 보너스(20 + 스프린트 번호 × 6)를 받습니다. 타워를 팔면 쓴 값의 70% 를 돌려받습니다.
  - 스프린트는 `git push` 버튼(Space)으로 시작합니다. 스프린트마다 버그 체력이 8% 씩 늘어납니다.
- **타워 5종, 3단계씩.** 🖨️ `console.log()` (싸고 빠른 한 마리 공격) · 🦆 러버덕 (둘레를 느리게) · 🧪 테스트 커버리지 (맞은 자리 둘레 폭발) · 🤖 AI 에이전트 (멀리서 세게, 갑옷 무시) · 🔥 방화벽 (둘레 화상).
- **버그 6종과 보스 2종.** 버그 · Off-by-one (빠름) · NullPointerException (갑옷) · Merge Conflict (쓰러지면 버그 둘) · Memory Leak (체력 회복) · 기술 부채 (느리고 갑옷 두꺼움) / 👑 왕버그 (쓰러지면 Off-by-one 넷) · God Class (쓰러지면 NullPointerException 셋). 그림은 Friday Deploy 의 버그를 그대로 씁니다.
- **빠르기 ×1/×2/×3, 일시정지.** 탭을 떠나면 웨이브 중인 판은 저절로 멈춥니다.
- **이어 하기.** 연결이 끊기거나 새로고침해도 같은 탭에서 10분 안에 돌아오면 멈춘 상태로 하던 판을 이어 갑니다.
- **순위표 (`git log --top`).** 막은 스프린트 → 남은 가용성 → 잡은 버그 순입니다. 스프린트를 하나 이상 막은 판이 오릅니다.
- **새 소식.** 타이틀의 버전 표기를 누르면 버전별 새 소식을 볼 수 있고, 새 버전을 처음 열면 한 번 저절로 뜹니다.
- **화면.** 세로 폰 기본, 가로 폰(맵 왼쪽, 버튼 오른쪽)과 데스크톱도 지원합니다. 키보드: 1~5 타워, Space 웨이브, F 빠르기, Esc · P 취소와 멈춤. 외부 이미지·소리 파일 없이 코드로 만든 픽셀 그림과 칩튠, 픽셀 폰트 Galmuri11 (SIL OFL 1.1, 저장소에 포함).

## 내부 변경

- **서버 권위 구조** (Friday Deploy 와 같은 원칙). 화면은 의도(`build · upgrade · sell · wave · speed · pause · restart`)만 보내고, 돈·가용성·버그·피해·결과·순위는 서버가 `packages/shared/src/sim.ts` 로 30Hz 고정 틱에 계산합니다. 상태는 웨이브 중 초당 15번, 짓는 중에는 바뀔 때만 보냅니다. 화면은 받은 상태의 모양을 확인하고 버그 위치를 두 상태 사이로 이어 그립니다.
- **보안** (`docs/SECURITY.md`): 1회용 HMAC 세션 토큰(10분, `SESSION_SECRET` 없으면 프로덕션 기동 거부), 같은 출처만 연결, 메시지 256바이트·초당 15개 제한(넘치면 끊음), 모양이 틀린 메시지 5번이면 끊음, IP 당 연결 4개·지켜 두는 판 3개, 동시 판 300개, 15분 무응답·10분 끊김이면 판을 닫음. 이어받기 키는 CSPRNG 192비트. 이름은 서버가 정리(NFKC, 글자·숫자·일부 기호, 12자)하고 화면은 `textContent` 만 씁니다. CSP 등 보안 헤더.
- **리더보드**: 판이 끝날 때 서버가 직접 남기고(점수를 제출하는 요청이 없음), 서버 시간보다 3배 넘게 빠른 판과 모양이 틀린 기록은 버립니다. 지금 시즌(0)의 상위 50개는 메모리에서 답하고, 저장은 뒤에서 재시도합니다. 종료할 때는 돌고 있던 저장을 기다리고 남은 기록까지 쓴 뒤 저장소를 닫습니다.
- **DB**: Neon PostgreSQL (`DATABASE_URL`, 풀링 주소 지원). 테이블 `runs` 는 처음 쓸 때 만들고, 모든 작업을 트랜잭션 안의 `SET LOCAL statement_timeout` 으로 감쌉니다. 파라미터 쿼리만 쓰고 기록을 지우지 않습니다. DB 가 없거나 죽어도 게임과 순위표 조회는 메모리로 동작합니다.
- **배포**: Render Blueprint (`render.yaml`, 웹 서비스 하나가 화면·API·WebSocket 을 서빙, 싱가포르, node 를 직접 띄워 종료 신호를 받음). `main` 에 새 버전이 들어오면 `.github/workflows/release.yml` 이 태그와 GitHub 릴리즈를 만듭니다.
- **릴리즈 절차**: `.claude/skills/release/SKILL.md`. 게임 안 새 소식(`releases.ts`)과 GitHub 릴리즈 본문(`docs/releases/`)의 규칙과 버전 일치를 테스트가 확인합니다.
- 처음 화면을 받을 때 gzip 기준 JS 약 14kB, CSS 약 2.5kB, HTML 약 2kB, 글꼴 약 490kB (한 번 받으면 캐시).
