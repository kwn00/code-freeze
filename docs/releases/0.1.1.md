# v0.1.1

## 달라진 점

- **순위표 (`git log --top`) 를 Friday Deploy 와 같은 모양으로 바꿨습니다.**
  - 줄마다 순위, 이름, 끝날 때 서 있던 타워(아이콘과 단계, 같은 종류·단계는 `×2` 처럼 묶음), 막은 스프린트(10개를 모두 막았으면 `🎉 프리즈 성공`), 남은 가용성, 잡은 버그, 날짜가 나옵니다. 1~3등은 순위 숫자에 색이 들어갑니다.
  - 방금 끝난 판이 순위표에 올랐으면 그 줄에 `내 기록` 표시와 초록 테두리가 붙고, 목록이 그 줄까지 내려갑니다. 그 사이 다른 기록이 앞에 들어와 순위가 밀려도 내용(이름·스프린트·가용성·잡은 버그)으로 찾습니다.
  - 불러오는 중(잠든 서버는 1분쯤), 기록이 없을 때, 불러오지 못했을 때(`↻ 다시 시도`), 기록이 서버 메모리에만 있을 때, 저장된 기록을 아직 불러오지 못했을 때를 각각 알려 줍니다.
  - 오른쪽 위 ✕, 패널 바깥 누르기, Esc 로 닫습니다. 열려 있는 동안 뒤 화면은 눌리지 않고, 같은 순위표는 15초 동안 다시 받지 않습니다.
- **웨이브 전에 지은 타워는 웨이브 전에 팔면 원가로 돌려받습니다.** 웨이브 사이(짓는 시간)에 짓거나 올린 값은 다음 웨이브가 시작되기 전에 팔면 모두 돌려받고, 패널의 버튼이 `↩️ 되돌리기 +N` 으로 바뀝니다. 웨이브가 시작된 뒤에 팔거나, 웨이브 중에 지은 타워를 팔면 예전처럼 쓴 값의 70% 입니다. 지난 웨이브를 넘긴 타워를 이번 짓는 시간에 올렸다면, 올린 값만 원가로 돌려받고 나머지는 70% 입니다.

## 내부 변경

- **순위표 응답** (`GET /api/leaderboard`): 줄마다 `rank`, `towers`(끝날 때 서 있던 타워: `[종류 번호, 단계]`, 종류 순·단계 높은 것부터), `version` 을 더했습니다 (`LeaderboardResponse`, `protocol.ts`). 저장소 id·시즌은 내보내지 않습니다.
- **DB** (`store-postgres.ts`): `runs` 표에 `towers jsonb` 열을 `ALTER TABLE … ADD COLUMN IF NOT EXISTS` 로 더합니다. 0.1.0 의 기록은 그대로 두고(타워는 NULL, 화면에는 타워 없이 나옴) 지운 기록은 없습니다. 리더보드 시즌(0)도 그대로입니다. 저장된 타워 값도 아는 종류·단계인지 확인하고, 틀리면 타워 없이 내보냅니다.
- **팔기** (`sim.ts`): 타워마다 `fresh`(이번 짓는 시간에 쓴 값)를 세고, `sellValue` = `fresh` + (`spent` − `fresh`) × 70% (내림). `startWave` 가 모든 타워의 `fresh` 를 0 으로 만듭니다. 판정은 서버에만 있고, 화면에 보내는 값(타워 줄의 7번째 값)은 버튼 문구용입니다.
- **통신 규격 1 → 2**: 타워 줄에 `fresh` 를 더했습니다. 예전 화면은 처음 연결할 때 `version_mismatch` 를 받아 새로고침 안내를 봅니다.
- **화면**: 순위표를 `leaderboard.ts` 로 옮겼습니다 (받은 줄의 모양 확인 `checkEntry`, 내 기록 찾기 `findMine`). 이름은 `textContent` 로만 넣습니다.
- 문서: README (팔기, 순위표), docs/SECURITY.md (팔기 값 부풀리기 행, 기록 확인에 타워 목록).

## 확인한 것

- 타입 검사, 클라이언트 빌드, 단위 테스트 43개 통과. 그중 PostgreSQL 테스트 3개는 로컬 PostgreSQL 16 에서 돌렸습니다: 타워를 포함한 저장과 순위대로 읽기, 0.1.0 모양의 표(옛 기록이 든 채)에 열을 더하고 옛 기록이 남는지, 저장소의 이상한 값(태그 이름, 범위 밖 스프린트, 모르는 타워)을 내보내지 않는지.
- 새 테스트: 원가로 되돌리기(짓고 팔기, 짓고 올리고 팔기, 웨이브를 넘긴 타워, 웨이브 중에 지은 타워, 웨이브를 넘긴 타워를 다시 올린 경우), 순위표 줄 모양 확인과 내 기록 찾기.
- 로컬 PostgreSQL 에 붙인 실제 서버에 브라우저(Chromium, iPhone 13)로: 빈 순위표 안내, 타워 2개를 짓고 판을 끝내 결과에 `순위표 1등` 이 뜨고 순위표에 타워 아이콘과 `내 기록` 이 나오는 것, 서버를 다시 띄운 뒤에도 기록이 남아 있는 것, 웨이브 전 `↩️ 되돌리기 +50` 으로 원가를 돌려받고 웨이브 중에는 `💸 팔기 +35` 인 것을 봤습니다. 콘솔 오류가 없습니다.
