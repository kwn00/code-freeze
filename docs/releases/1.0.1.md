# v1.0.1

## 고친 것

- **빠르기 버튼과 일시정지 메뉴가 깜빡이던 것.** 웨이브 중에 `×1` 을 누르면 `×2` → `×1` → `×2` 로, 일시정지(Ⅱ, Esc, P)를 누르면 메뉴가 떴다 사라졌다 다시 떴습니다.
  - 원인: 버튼을 누르면 화면은 바로 바뀌지만, 서버가 그 입력을 받기 직전에 보낸 상태(웨이브 중에는 초당 10번 옵니다)가 뒤늦게 도착합니다. 화면은 받은 상태를 그대로 다시 그려서 잠깐 옛 값으로 돌아갔다가, 입력을 반영한 다음 상태가 오면 다시 바뀌었습니다. 통신이 느릴수록 잘 보였습니다.
  - 고친 것: 누른 값을 기억해 두고, 서버가 같은 값을 보낼 때까지(최대 2초) 누른 값을 보여 줍니다. 판정은 그대로 서버가 합니다: 서버가 끝내 다른 값을 보내면 2초 뒤에는 서버 값을 따릅니다. 연달아 누르면 마지막 것을 기다립니다. 키보드(Esc, P)로 멈추고 풀 때도 같은 값을 봅니다.

## 내부 변경

- `apps/client/src/pending.ts`: 누른 값을 서버가 확인할 때까지 붙잡아 두는 작은 도구 (`Pending`). 빠르기와 멈춤에 씁니다. 예전의 빠르기 전용 처리(`wantSpeed`, 1초)를 이것으로 바꿨습니다.
- 서버와 통신 규격은 그대로입니다. 리더보드 시즌(1)과 기록도 그대로입니다.

## 확인한 것

- 타입 검사, 클라이언트 빌드, 단위 테스트 68개 통과 (새 테스트: 늦게 온 옛 상태에 밀리지 않기, 서버가 확인하면 서버 값 따르기, 끝내 받지 않으면 2초 뒤 서버 값, 연달아 누르기).
- 입력이 서버에 150ms 늦게 닿게 한 서버 사본에 브라우저(Chromium, iPhone 13)로 웨이브 중 빠르기·일시정지·계속하기를 눌러 화면 값을 20ms 마다 기록했습니다. 1.0.0 에서는 `일시정지 → 닫힘 → 일시정지`, `×3 → ×1 → ×2 → ×1` 이 나왔고, 이 버전에서는 누를 때마다 한 번씩만 바뀝니다.
